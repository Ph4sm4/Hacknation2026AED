# Zakres wykorzystania AI

Zgodnie z §2 ust. 7–8 regulaminu zadania zespół deklaruje zakres użycia sztucznej inteligencji.

| Obszar | Rola AI | Rola zespołu |
|---|---|---|
| Analiza zadania | streszczenie wymagań i kryteriów oceny | priorytety, decyzje o zakresie |
| Wzorcowy zakres danych | propozycja listy pól i ich opisów | wybór pól, wymagalność, słowniki, akceptacja |
| Źródła danych | wyszukanie zbiorów AED w API dane.gov.pl, odnalezienie XSD harwestera w kodzie źródłowym portalu | weryfikacja źródeł i licencji |
| Kod (Python, TypeScript) | generowanie kodu wg wskazań zespołu | architektura, przegląd, testy, poprawki |
| Logotyp i księga znaku | wektorowe szkice znaku, skład księgi | koncepcja (pinezka + serce + błyskawica), nazwa i hasło, wybór wariantów |
| Teksty interfejsu | wersje robocze | redakcja i akceptacja |

Ostateczny kształt rozwiązania jest efektem analizy i pracy zespołu, który posiada do niego wszelkie prawa.
